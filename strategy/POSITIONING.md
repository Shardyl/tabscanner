# Tabscanner — Positioning & USP

The single source of truth for **what this brand is** and **why anyone should choose it**.
The entity claim authored here is reused by `SEO-STRATEGY.md`, the AEO work, and every page.

## The entity claim (authored HERE; referenced everywhere)
> Tabscanner is a **receipt OCR API** (tabscanner.com) that turns photos/scans of receipts into
> structured, line-item data, used by businesses for expense management, loyalty programs, and
> market research. <!-- drafted from build context; confirm exact wording via Q8 -->

## Product & primary conversion  (operator-clarified 2026-06-13)
- The **receipt uploader is baked directly into the homepage** (the live demo uploader,
  `theme/inc/demo-uploader.php` + `assets/js/uploader.js`). **There is NO separate app** — visitors
  upload receipts on the website itself, so **every receipt upload IS a website visit** to
  tabscanner.com. It is the site's **primary on-page engagement / conversion**.
- Because of this, the daily upload activity the operator sees on the internal dashboard is real
  website traffic. Now that GA4 is live on the homepage (`G-HF2H4PDB7W`), GA should line up with
  that internal dashboard going forward (before today there was **no GA tag on the site at all**).
- **No paid ads — all organic.** Real GSC data (28 days, non-www property): **~29,900 impressions,
  ~341 clicks** — substantial daily organic search → homepage → upload. Core query positions
  (GSC 28-day average): `receipt ocr` ~16, `receipt ocr api` ~20, `ocr receipt scanner` ~12,
  branded `tabscanner` ~7.5.
- **On the "#1" perception:** the operator sees Tabscanner at #1 for the core terms in their own
  (personalised / UAE) searches, but GSC's *average* position is lower (~16-20) because it averages
  across all locations/users/time. That gap is the **opportunity**: e.g. "receipt ocr api" gets
  839 impressions/28d but sits page-2 on average — getting it onto page 1 would multiply the clicks.
  Big, addressable SEO upside on already-relevant terms.
- **GSC access RESOLVED 2026-06-13:** the real data lives on the **non-www `tabscanner.com`**
  property (www 301s to it; the WEBSITES login previously only had the empty www shell, owned
  elsewhere). Verified non-www under this account via the GA method (Site Verification API) →
  now `siteOwner`, real data flows. DNS is managed by CTO **Ben Smith** at Cloudflare (domain-property
  route would need a TXT from him).
